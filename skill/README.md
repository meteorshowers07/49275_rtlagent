# RTL 技能包 v0.1

当前是一份**待实验验证的初始规则集**，不是已经证明提高竞赛通过率的技能成果。`rtl_rules.md` 由 agent 系统提示加载；baseline 不加载。规则是工程假设，不来自本项目真实模型失败案例，尚未获得消融增益。

| 规则类别 | 适用场景 | 使用与失效边界 | 当前验证 |
|---|---|---|---|
| 接口保持 | 按题面实现独立 RTL 模块 | 保留端口、宽度、周期语义；不适用未说明的接口推断 | 软件测试确认规则进入 agent 提示 |
| 顺序/组合赋值 | 计数器、状态机、数据通路 | 根据时序语义选阻塞/非阻塞；不能替代仿真 | 待真实样本与消融 |
| 宽度与符号 | 算术、比较、移位 | 显式扩展和截断；题面有歧义时仍可能失败 | 待实测 |
| 复位与周期对齐 | 同步/异步复位、使能、流水线 | 不擅自增加延迟；需可信参考确认 | 开发示例提供测试台，尚未真实仿真 |
| 诊断修复 | 编译/仿真/综合失败 | 输入程序返回的日志摘要，输出完整设计；预算有限 | 替身测试验证重试和回退 |
| 可综合限制 | 独立、无外部文件的 RTL | 不含 testbench、DPI、外部 include；复杂 IP/外部文件任务超出首版范围 | 替身测试检查拒绝与分级判定 |

后续每新增规则必须记录：开发集失败 ID、原始诊断、原因假设、适用边界、修复前后设计哈希、同模型同预算对照、保留集效果。分别比较裸跑、仅模板、仅反馈、反馈加技能；没有结果的格子写“未测”。评测窗口内不新增规则。
