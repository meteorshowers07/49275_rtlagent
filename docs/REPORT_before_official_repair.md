# 3.1 RTL 本地智能体设计报告（首版）

2026-10-09 新版进展见 [第二轮优化与验收](docs/optimization_round2.md)，本轮 131 项软件测试通过；下列历史评测记录没有替换为真实模型成绩。

## 完成状态与目标

本阶段完成要求分析、详细工作计划、可本机运行的软件首版、156 题公开集导入及划分、串行多种子批处理和 HTTP 流程自检。目标是在单张 32 GB AMD GPU 上，用本地开放权重模型结合 Vivado 2025.2 反馈，提高硬件生成题的末级通过率，并计量相对同模型裸跑的增益与墙钟成本。

**未完成真实模型/公开数据集/EDA/GPU/离线容器验收，当前不存在可报告的竞赛通过率或显存成绩。** 不将人工回放或工具替身测试视为真实能力。

## 架构与实现依据

单题输入经本地模型生成 RTL，程序顺序调用编译、仿真、综合；失败时仅向模型回送最近候选与有限诊断。达到完整成功、出现重复候选、工具不可用、无法验证或预算耗尽时终止。保存已达到最高连续验证级别的候选，不让后续较差修复覆盖它。

基线使用同一服务、上下文与采样配置；仅题目、单次生成。配对脚本在同次运行中独立产出两路结果。基线评分由外部评测步骤完成，不参与基线生成。详见 `docs/interface.md`。

这样设计的依据是指南评分中增益占 40，能力占 30，墙钟占 10，工程质量占 20。优先验证能否稳定修复真实失败，再决定是否增加复杂规划、检索或微调；这些策略均未实现，也无效果结论。

## 模型选择

初始候选及声明见 `model/MODEL.md`。先使用较小代码模型跑通框架，之后在固定开发题集和相同资源条件下比较候选。权重未下载、版本未锁定、显存未测，没有已评估且淘汰的候选。最终报告将根据实测重写本节。

## 智能体与技能

当前最多三次生成，记录逐轮请求、响应、种子、usage（后端提供时）、停止原因与工具日志。上下文包含原题、规则、最近候选和诊断，避免堆积历史。技能包覆盖接口、赋值、位宽、复位与综合约束，目前仅为待验证规则，来源与边界见 `skill/README.md`。

## 待执行实验表

固定题集版本、任务清单、模型、服务与预算；开发集和保留集分离。每个样本保存原始结果和全部成本，失败/超时/不可判定项单列。比较裸跑、仅规则、仅反馈、完整方案；再对模型候选做相同协议对照。分级汇总 pass@1/5、百分点增益、平均耗时和 P50/P95；如无足够完整独立样本，pass@5 留空。最终指标定义服从赛事细则。

## 失败分析与范围

目前仅能分析软件错误路径，不能宣称已发现某类真实模型薄弱题。预期分析分类包括语法/展开、位宽符号、复位优先级、周期错位、状态机、综合不支持、上下文溢出、超时和 OOM。首版仅支持自包含单候选源码、简单顶层标识符、可信开发测试台；含外部 include、IP、多时钟约束、未知测试输出协议的任务需后续适配。
