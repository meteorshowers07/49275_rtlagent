## 预算与判定

HTTP 时限从入队前的 monotonic 时间起算。排队耗尽或不足 10 秒时不再启动子进程；服务在 deadline-10 秒触发终止，预留进程回收与返回时间。agent 在传入剩余时限内再预留 20 秒，所有模型/EDA 调用共享绝对截止时间；不会给每个工具重置一份预算。官方 baseline 固定的 840 秒内部超时不修改，由外层限制请求总时限。独立目录调用 baseline 时也应由调用方执行进程组超时控制。

原有本地 JSON 工作流仍使用 serve/config.json 的 run_timeout_s 和 tool_timeout_s，并在给定 AGENT_DEADLINE_S 时取更小的剩余预算。未凭单题记录任意调大全局预算。

运行时 rank 只用于候选保留，不对应 L0/L1/L2/L3/L4。工具崩溃、启动异常或预算用尽时停止修复并保留已有较好候选。超时而无独立崩溃证据时保留超时分类。
